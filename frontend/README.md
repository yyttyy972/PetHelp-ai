# 邻宠帮前端 · A 第十周阶段版

Vue 3 + TypeScript + Vite。默认模拟模式，可在“连接设置”切换到 B 的后端。第九周原型保留在 src/App.vue，本周入口为 src/Week10.vue。

## 启动

Node.js 22或24，在 frontend 执行 `npm ci`、`npm run dev`，打开终端显示的地址。构建执行 `npm run build`。

## 功能

- 新增/编辑宠物，填写帮手档案和可服务时间。
- 三类需求、多宠物选择、逐项清单、费用、草稿核对与导出。
- 模拟三类发布；后端模式接入注册登录、档案、代看/遛狗创建草稿、修改草稿和按版本发布。
- 大厅、我的需求、详情、筛选、分页及错误提示。
- AI 请求及503手动回退；成功响应只展示建议，自动映射待C确认。

## 连接后端

先按 ../backend/README.md 启动后端。在连接设置选择后端模式，地址默认 http://127.0.0.1:8000/api/v0，注册或登录。令牌仅保存在内存，刷新需重新登录。仅填写你信任的后端地址。
CORS须允许前端实际端口，若Vite使用5174，请更新B的CORS_ORIGINS。不会在后端失败时伪造成功。
三类需求均可提交到真实后端。代买的 `budget` 表示商品预算；发布阶段没有独立服务报酬字段，服务报酬在预约的 `agreed_fee` 中约定，实际商品费用记录到 `actual_cost`。用品位置写入相关清单内容，路线写入 `requirements`，行为注意和禁止事项写入 `precautions`。导出文件含地点和联系人，仅保存到自己的设备。

## 测试

运行 `npm run build` 和 `npm test` 完成前端构建、模拟流程及HTTP契约桩验证。启动本地 PostgreSQL 与后端后，运行 `npm run test:real` 完成真实数据库联调。默认使用已安装的 Microsoft Edge；无 Edge 可将 playwright.config.ts 的 channel 改为 chromium，并执行 `npx playwright install chromium`。测试会启动或复用本项目 Vite。

真实联调覆盖注册登录、宠物与帮手档案、可服务时间、代看与遛狗需求的创建/修改/发布、我的需求和大厅隐私。每次运行会创建带 `a_week10_` 前缀的本地测试账号及配套数据，仅用于开发数据库。

## 边界

模拟数据仅存当前会话，刷新/切换模式会清空。后端草稿可从我的需求详情重新打开编辑。宠物列表最多载入100项。后端缺少本人帮手档案查询接口，暂仅支持提交，不承诺跨会话自动恢复。AI 自动映射继续等待 C 确认；无图片上传界面、真实匹配、预约执行和结算。
