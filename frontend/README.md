# 邻宠帮前端 · A 第十周阶段版

Vue 3 + TypeScript + Vite。默认模拟模式，可在“连接设置”切换到 B 的后端。第九周原型保留在 src/App.vue，本周入口为 src/Week10.vue。

## 启动
Node.js 22或24，在 frontend 执行 `npm ci`、`npm run dev`，打开终端显示的地址。构建执行 `npm run build`。

## 功能
- 新增/编辑宠物，填写帮手档案和可服务时间。
- 三类需求、多宠物选择、逐项清单、费用、草稿核对与导出。
- 模拟三类发布；后端模式接入注册登录、档案、代看/遛狗创建草稿、修改草稿和按版本发布。
- 大厅、我的需求、详情、筛选、分页及错误提示。
- AI 请求及503手动回退；成功响应只展示建议，自动映射待B/C确认。

## 连接后端
先按 ../backend/README.md 启动后端。在连接设置选择后端模式，地址默认 http://127.0.0.1:8000/api/v0，注册或登录。令牌仅保存在内存，刷新需重新登录。仅填写你信任的后端地址。
CORS须允许前端实际端口，若Vite使用5174，请更新B的CORS_ORIGINS。不会在后端失败时伪造成功。
代买商品预算字段未确认，真实代买提交暂被阻止，但可导出完整草稿。补充要求由用户明确填入B已有的requirements文本字段，结构化映射仍待确认。导出文件含地点和联系人，仅保存到自己的设备。

## 测试
运行 `npm run build` 和 `npx playwright test`。默认使用已安装的Microsoft Edge；无Edge可将playwright.config.ts的channel改为chromium并执行 `npx playwright install chromium`。测试会启动或复用本项目Vite。
测试覆盖三类模拟流程、档案编辑、修改后旧版本发布拦截及HTTP契约桩。契约桩不等于真实数据库联调。

## 边界
模拟数据仅存当前会话，刷新/切换模式会清空。后端草稿可从我的需求详情重新打开编辑。宠物列表最多载入100项。后端缺少本人帮手档案查询接口，暂仅支持提交，不承诺跨会话自动恢复。无图片上传界面、真实匹配、预约执行和结算。
