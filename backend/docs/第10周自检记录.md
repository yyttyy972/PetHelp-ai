## 执行命令

常规环境可在 backend 目录执行：

```powershell
psql -U postgres -d linchong -v ON_ERROR_STOP=1 -f db/schema.sql
psql -U postgres -d linchong -v ON_ERROR_STOP=1 -f db/seed.sql
psql -U postgres -d linchong -v ON_ERROR_STOP=1 -f db/seed.sql
.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
.venv/Scripts/python.exe tests/smoke.py
```

本次使用便携PostgreSQL，通过 psycopg 将这三个 SQL 文件执行到空库，测试实例仅监听127.0.0.1:55432，数据库启动需要本机套接字权限；测试服务监听127.0.0.1:8000，启动配置见README。未修改系统PostgreSQL服务。
