# A 第十周阶段交付与验证

负责人：董韵曦。基于本地B后端13bda14和第九周前端。按用户要求先独立推进，不再向D请求确认。

## 已实现
1. 宠物新增/编辑、帮手档案、可服务时间。
2. 三类发布表单、多宠物选择、清单及完成条件编辑；遛狗限制犬类及固定节点，代买商品信息与服务费分离。
3. 核对、导出、保存草稿、发布分离；修改后必须重新保存，防止误发布旧版本。
4. 注册/登录、档案、代看/遛狗需求创建修改发布、列表/详情接口层；状态以服务端响应为准。
5. 大厅公开投影、我的需求详情、筛选、分页、空状态、刷新和失败提示。
6. AI请求与503回退，失败保留输入；成功只展示建议与补问，不自动猜测映射。

## 接口约定
北京时间选择转为带+08:00时间；金额为两位小数字符串；宠物使用ID数组。创建不传owner_id/status，发布独立传expected_version。令牌仅在内存，15秒超时，401清凭证、403显示拒绝、409提示刷新版本、422显示消息。
创建同正文重试复用幂等键，正文变化换键；发布重试复用键。其他写操作有幂等键和处理中禁用，但不保证跨超时手动重试完整幂等恢复。
